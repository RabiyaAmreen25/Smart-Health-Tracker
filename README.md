# Smart Health Tracker

**Smart Health Tracker** is a lightweight and intuitive web app that helps users track basic health metrics — water intake, calories consumed, and body mass index (BMI) — all in one place. The project also includes helpful health tips to encourage daily wellness habits. :contentReference[oaicite:2]{index=2}
